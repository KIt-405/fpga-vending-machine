# FSM-Based Vending Machine Digital System

An implementation of a classic vending machine controller on an FPGA, utilizing a strictly partitioned Datapath Unit (DPU) and an FSM-based Control Unit (CU) architecture. Designed in synthesizable Verilog and targeted for the Altera DE2 development board using Intel Quartus Prime.

## Hardware Architecture
The system architecture is divided into two core segments to optimize timing closure and maximize design scalability:
* **Control Unit (CU):** A synchronous Finite State Machine (FSM) that processes user inputs and monitors status flags generated by the datapath to navigate transaction states.
* **Datapath Unit (DPU):** Houses the arithmetic and stateful processing hardware, including coin tracking registers, magnitude comparators, and operational counters.

## Key Features
* Modular RTL Design (Registers, Multiplexers, Adders, and Counters)
* Input Edge Detection & Basic Hardware Debouncing
* Complete Intel Quartus Synthesis and Compilation Flow
* Behavioral Verification via ModelSim Simulation Waveforms
